# Description

This is my own Neovim configuration, built from [kickstart](https://github.com/nvim-lua/kickstart.nvim). While the default configurations were nice, to make it more custom for myself, I've decided to build on top of the fork to better understand how both Lua and Neovim works.

Changes I've implemented myself:

1. Added non-default plugins. 
2. Fully switched to `vim.pack`. Yanked most of it from Kickstart, though
